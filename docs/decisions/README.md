# 결정 기록 (decisions)

프로젝트 동안 내린 구조 · 인터페이스 · 동작 결정과 그 이유를 날짜순으로 남긴 기록이다. 결정 번호(E1~E71)는 설계 문서 · 결과표 · 코드 주석에서 그대로 인용한다.

## 핵심 결정

| 번호 | 결정 | 이유 |
|---|---|---|
| E13 | 그릇 닦기: 바닥은 접촉 하강으로 찾고, 벽면은 치수로 정한 반지름을 따라 힘제어 1.5 N 으로 닦는다 | 수세미가 물러 접촉 깊이가 실행마다 12~17 mm 로 달라 티칭 높이 하나로 맞출 수 없다 |
| E17 | 정지 방식은 `DR_QSTOP`(최대 감속 정지) | 서보 전원과 위치를 유지하므로 일시 정지 뒤 재개할 수 있다 |
| E18 | 세제 수조를 따로 두지 않고 툴 홀더의 비눗물 컵에 툴을 담근다 | 세제 자리를 따로 티칭하지 않고 툴 홀더 좌표와 담금 깊이로 계산한다. 수조는 헹굼 수조 하나만 남는다 |
| E26 | 툴 · TCP 는 시작 전에 이름만 확인하고, 다르면 움직이지 않고 종료한다 — ROS 로 바꾸거나 모드를 전환하지 않고 펜던트에서 고친다 | 툴 · TCP 선택이 풀려 좌표가 208 mm 아래로 간 일([TS-07](../troubleshooting/TS-07_TCP_설정_풀림_충돌.md)). 자동 모드에서는 설정 변경이 거부되고, 모드 전환 중 다른 프로그램이 움직이면 위험하다 |
| E41 | 반납 구역마다 고정 슬롯 2개 — 그릇 2 · 컵 2 를 처음부터 배치하고 슬롯 1 → 슬롯 2 순으로 집는다 | 강사 피드백으로 정한 시연 시나리오. 슬롯 1 이 비면 슬롯 2 로 가므로 집기 코드는 그대로다 |
| E44 · E50 | 놓기 · 적재 · 툴 반납 · 컵 재파지는 접근점에서 자세를 맞춘 뒤 Z 만 곧게 내린다(마지막 15 mm 는 30 mm/s 로 완충) | 용기 · 툴 · 홀더는 항상 지정 좌표에 있고 동선은 실기로 검증했다. 힘 감시는 접촉 동작(닦기 · 안착 탐색 · 바닥 찾기)에 쓴다 |
| E52 | 예외 처리 재설계 — 로봇 오류는 그 자리에서 멈추고 사람 신호를 기다린다, 잔반 남음은 자동 격리, 툴 집기 실패는 멈춤, 격리 정리는 함수 하나로 | 정책상 격리가 기록만 남고 로봇이 용기를 옮기지 않던 빈틈을 닫는다(모든 격리 = 실제 격리). 로봇 오류 뒤에는 위치를 모를 수 있어 사람이 받은 뒤에만 움직인다 |
| E60 | 닦기 중 힘 상한 · 시간 초과가 나면 남은 나선 · 주기 운동을 즉시 멈추고 힘 · 순응을 끈 뒤 곧게 위로 | 전에는 남은 동작(그릇 나선 최대 약 2 s · 컵 솔 주기 운동 최대 약 14 s)을 끝까지 기다린 뒤 올라갔다 |
| E62 | 툴 놓침 뒤 재개는 곧게 위로 → 툴 집기 → 세제 → 닦기 순서로 다시 한다 | 닦기 함수는 용기 바로 위에서 곧게 내려가므로, 홀더 자리에서 불리면 홀더 쪽으로 약 140 mm 내려갈 수 있었다 |
| E64 | 케이블 멈춤은 로봇팔을 가볍게 밀거나 화면에서 재개하면 바로 풀리고, 무게 단계를 처음부터 다시 한다(제자리 재측정 없음) | 9/29 실기에서 제자리 재측정 중 손이 닿아 무게 떨림이 튀었고, 다섯 번 밀어야 재개됐다 |
| E65 | 격리 자리는 그릇 · 컵 한 곳. 격리할 때 스펀지 홈의 용기는 놓았던 자세에서 위로 다시 잡는다 | 옆면으로 다시 잡은 용기는 격리 구역에 옆으로 놓였다. 그릇 전용 격리 경로를 없애 경로를 하나로 줄였다 |
| E67 | 실기 실행의 기본 배속 1.0 | 9/29 1회차(무정지 약 13분) · 2회차 예외 · 리허설을 모두 1.0 으로 돌려 문제가 없었다 |
