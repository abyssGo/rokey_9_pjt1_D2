# TS-02 실기 브링업 실패 — `gripper_joint_state_publisher.py` 실행 권한 누락

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-09-18 |
| 발견 | 민범진 (V-02 사전 검증 준비 중) |
| 영향 | **실기(`sodreal`)를 아예 띄울 수 없음.** 배포본 문제라 4대 모두 해당 가능 |
| 상태 | **해결 완료** — 실기 PC 브링업 정상(9/18 민범진 PC 확인 · 9/22~9/29 통합 실기) |

## 1. 증상
```
$ sodreal
[ERROR] [launch]: Caught exception in launch (see debug for traceback):
executable 'gripper_joint_state_publisher.py' not found on the libexec directory
'/home/<user>/ws_cobot_pjt/ws_dsr/install/m0609_rg2_bringup/lib/m0609_rg2_bringup'
```

**Virtual(`sodvir`)은 정상 동작한다.** 그래서 환경 점검(ENV-01)을 통과하고도 실기에서만 드러난다.

## 2. 원인
파일은 있는데 **실행 권한이 없다.** `ros2 launch`는 실행 권한이 없는 파일을 "없는 파일"로 취급한다.

```
$ ls -l ~/ws_cobot_pjt/ws_dsr/src/rg2/m0609_rg2_bringup/scripts/
-rw-rw-r--  gripper_joint_state_publisher.py    ← 실행 권한 없음
-rwxrwxr-x  gripper_virtual_node.py
-rwxrwxr-x  joint_state_merger.py
-rwxrwxr-x  rg2_joint_state_republisher.py
```

4개 중 하나만 빠져 있다. 배포본 자체의 문제로 보인다.

Virtual과 Real이 **서로 다른 노드를 띄우도록** 런치 파일에 조건이 걸려 있어서 증상이 갈린다.

`m0609_rg2_bringup/launch/bringup.launch.py`
```python
gripper_virtual_node          = Node(..., condition = IfCondition(is_virtual))   # virtual 전용
gripper_joint_state_publisher = Node(..., condition = IfCondition(is_real))      # real 전용
```

| 모드 | 띄우는 노드 | 권한 | 결과 |
|---|---|---|---|
| Virtual `sodvir` | `gripper_virtual_node.py` | 있음 | 정상 |
| **Real `sodreal`** | `gripper_joint_state_publisher.py` | **없음** | **실패** |

## 3. 해결
```bash
chmod +x ~/ws_cobot_pjt/ws_dsr/src/rg2/m0609_rg2_bringup/scripts/gripper_joint_state_publisher.py
```
`--symlink-install` 이라 **다시 빌드할 필요 없다.** 소스 파일 권한만 고치면 바로 반영된다.

확인:
```bash
ls -l ~/ws_cobot_pjt/ws_dsr/src/rg2/m0609_rg2_bringup/scripts/    # 4개 모두 rwx
sodreal
ros2 node list | grep gripper_joint_state_publisher               # 노드가 뜨면 성공
```

## 4. 재발 방지
- 실기를 처음 쓰는 PC는 `sodreal` 전에 위 `ls -l` 로 4개 파일 권한을 확인한다.
- `ws_dsr` 은 "강사 배포, 수정 금지"지만 이건 **내용 변경이 아니라 권한 한 비트**이고, 되돌리기도 `chmod -x` 한 줄이다.

## 5. 확인한 범위와 남은 확인
- 확인: 민범진 PC에서 해결 후 실기 브링업 성공, `gripper_joint_state_publisher` 노드 기동 확인
- 이후: 9/22~9/29 통합 실기에서 실기 브링업(`sodreal`)이 계속 정상이었다. 다른 PC 에서 실기를 처음 띄울 때는 §4 대로 권한부터 본다.
