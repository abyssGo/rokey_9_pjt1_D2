스크립트가 도는 순서(회차마다 4가지):

| 단계 | 무엇을 하나 | 눈으로 볼 것 |
|---|---|---|
| ① 관절 이동 중 일시정지 → 재개 | J1 을 30° 도는 도중 멈춘다 | **그 자리에서 서고**, 재개하면 **이어서** 30° 를 채운다 |
| ② 직선 이동 중 일시정지 → 재개 | 옆으로 80 mm 가는 도중 멈춘다 | 곧게 가다 서고, 이어서 80 mm 를 채운다 |
| ③ 강제정지(halt) | 도는 도중 강제정지 | 그 자리에서 **끝난다**. 풀기 전에는 새 이동이 안 나간다 |
| ④ 멈춰 있을 때 누른 일시정지 | 먼저 눌러 두고 이동을 시킨다 | **출발하지 않다가** 재개 뒤에 출발한다 |

## 4. 막혔을 때

| 증상 | 조치 |
|---|---|
| `KeyError: cell.yaml 의 … 가 비어 있다` | 한석형이 `limits`·`motion` 을 채워야 한다. 그 전에는 **로봇을 안 움직이는 것이 정상** |
| `MoveIncomplete: … 도중에 멈췄다` | 컨트롤러가 이동을 세웠다(속도·관절 한계·특이점). 로봇 위치를 확인하고, `vel_scale` 을 더 낮춰 다시 |
| 일시정지를 눌러도 안 선다 | `check_motion` 폴링이 도는 이동인지 확인. 🚨 힘제어·`move_periodic`(닦는 중)에는 **원래 안 먹는다**(그 동작이 끝난 뒤 다음 이동에서 멈춘다 — IRD §6) |
| 브링업이 조용히 실패 | 포트 12345 잔류 → `killdrcf` 뒤 다시 |
