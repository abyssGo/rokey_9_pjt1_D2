# 조사 자료 (research)

주제 선정("왜 이 주제인가")과 발표 브리핑에 쓴 조사 자료다. 9/17 조사 시점의 자료라 최종 구현과 다른 구상(예: 반납구 신호로 종류 식별)이 들어 있다. 최종 구현은 [설계 문서](../03_설계_SDD.md)와 [결과표](../04_결과_결과표.md)를 따른다.

| 파일 | 내용 |
|---|---|
| [법규_산업조사.md](법규_산업조사.md) | 경기장 다회용기 관련 법령 · 정책 흐름 · 우리 프로젝트에 쓸 논리 · 발표에서 과장하지 말 것. 경기장 다회용기 사용을 직접 의무화한 법은 없고, 회수 용기의 세척 · 재사용 위생기준이 법령에 기반해 명문화돼 있어 "예비세척 → 식기세척기" 구조의 근거가 된다 |
| [브리핑_자료정리.md](브리핑_자료정리.md) | 팀원이 공유한 기사 · 영상 · 사진과 추가 조사를 발표 브리핑 순서로 정리 — 한 장 요약 · 현장 사례(서울시 · 지자체 · 구단 · 세척센터) · 현장의 문제 · 우리 프로젝트가 서는 자리 · 출처 |
