# 법규·산업 조사 — 경기장 다회용기 (발표 "왜 이 주제인가" 근거)

> 2026-09-17 조사. 수치는 출처 링크 기준, 발표 전 재확인.

## 1. 결론 요약
- **경기장에서 다회용기 사용을 직접 의무화한 법은 없다.** 법이 하는 건 ① 체육시설 **일회용 응원용품** 규제 ② **다회용기 세척 위생기준**(환경부·식약처 지침) ③ 지자체 **조례·보조사업**이다.
- 실제 도입은 **서울시(잠실·고척)·인천(SSG)·창원(NC)** 등 지자체·구단 주도. 2026년 기준 전국 야구장 매장의 **99.7%가 여전히 일회용품** 사용 → 확대 여지가 큼.
- 회수된 다회용기의 **세척·재사용 공정 위생기준이 법령(식품위생법·순환경제법) 기반으로 명문화**돼 있음 → 우리 "예비세척 → 세척기" 구조의 근거.

## 2. 법령

| 법령 | 내용 | 우리와의 관계 |
|---|---|---|
| **자원의 절약과 재활용촉진에 관한 법률 §10** + 시행규칙 | 체육시설(운동장·체육관·종합체육시설)에서 **합성수지 1회용 응원용품 사용 억제·무상제공 금지** (2022.11.24 시행, 과태료 300만 원 이하). 이후 개정으로 경기장 내 일회용 응원용품 판매 금지, 주류 구매 시 일회용컵 제공 중단 | 경기장을 일회용품 규제 대상으로 명시 → 다회용기 전환 압력 |
| **순환경제사회 전환 촉진법** · **식품위생법** | 다회용기 재사용의 위생·세척제·용기 기준 근거 | 세척 공정 기준의 상위법 |
| **환경부·식약처 「다회용기 세척 위생기준 가이드라인」 (2023.7.31)** | 세척장 조성·세척·위생관리 방법, 용기 세척·폐기 기준, 미생물·잔류세제 신속검사, 다회용컵 규격(355/414/473 mL, 두께 ≥1 mm, 외경 92~98 mm), **대여·반납 수량 전산 관리** | 🎯 **우리 시스템의 직접 근거** — 세척 전처리 + 수량 전산 기록 |
| 환경부 「다회용기 보급 국고보조사업 실행지침」 (2023.7) | 지자체 다회용기 보급 사업 기준 | 도입 확산의 재정 근거 |
| 서울시 조례·정책 | 2024.9부터 **1천 명 이상 행사 일회용품 전면 금지·폐기물 감량계획 의무화**, 잠실·고척 다회용기 사업(시의회 업무협약 2024.4) | 지자체 단위 의무화 사례 |

## 3. 정책 흐름
- 2023.4 KBO·10개 구단 ↔ 환경부 **일회용품 감축 협약**
- 2024.4 서울시, **잠실야구장 38개 매장 다회용기 전국 최초 도입** (10종, 반납함 20개, 목표 80만 건·24 t 감축) → 시즌 60만 건, 약 17 t 감량
- 2025 환경부: 일회용품 정책을 **규제 → 지원**으로 전환, **다회용기 재사용 촉진 100억 원**
- 2026.6 경향신문·환경단체 조사: 전국 9개 구장 350개 매장 중 **일회용품 미사용 1곳(0.3%)**, 다회용기 미도입 256곳(73.1%). 도입률 인천 50.0% · 수원 38.2% · 잠실 34.7% · 고척 29.3% · 대구 2.4%
- 회수율: 잠실·고척 2024 74.2% → 2025 79.0% → **2026 85.4%**, 인천 SSG 2025 약 98%
- 야구장 연간 폐기물 3,444 t (2022) — 스포츠 시설 중 최다

## 4. 우리 프로젝트에 쓸 논리
1. **법·정책이 다회용기 전환을 밀고 있다** — 응원용품 규제(2022), KBO 협약(2023), 서울 도입(2024), 환경부 100억 지원(2025), 회수율 85%(2026).
2. **그런데 매장의 99.7%가 아직 일회용** — 확대의 병목은 "회수 후 세척"이다. 회수량이 경기 직후에 몰리고, 세척 위생기준(2023 지침)을 지키려면 **애벌세척·분류·적재**라는 젖은 반복 노동이 필요하다.
3. **우리 시스템은 그 전처리를 로봇으로** — 반납 신호로 종류 식별, 잔반 분리, 예비세척, 세척기 트레이 적재, **수량 전산 기록**(지침의 전산 관리 요구와 일치). 본세척은 세척기가 지침대로 수행한다.
4. 협동로봇 1대 + 3D 프린팅 지그라 **구장별 매장 단위로 설치**할 수 있어, 대형 세척 공장이 없는 지방 구장(대구 2.4%, 광주 9.7%)에 맞는다.

## 5. 주의 (발표에서 과장하지 말 것)
- "다회용기 의무화 법"은 없다. "규제·지원 정책이 확산을 밀고 있다"로 표현.
- "닦였다"를 로봇이 판정하지 않는다. 위생 적합성은 지침에 따른 **본세척(세척기)** 이 담당.
- 회수율·도입률 수치는 기사 기준(2026.6). 발표 전 최신 수치 재확인.
