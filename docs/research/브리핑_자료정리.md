### 사진 (팀원 제공) — 세척장 트레이 적재 라인
장갑·앞치마를 낀 작업자 3명이 **컨베이어 위 핀 랙(peg rack)에 그릇·접시를 하나씩 세워 꽂고** 있다. 컵·그릇은 뒤집어 세우고, 접시는 핀 사이 세로로.
→ **이게 정확히 우리가 자동화하는 공정**이다. 본세척기(컨베이어) 앞단의 "종류 분류 → 자세 변환 → 핀 랙 적재"가 전부 손이다. 우리 트레이 인서트(컵 돌기·그릇 경사 받침·접시 세로 슬롯)는 이 핀 랙과 같은 개념.

| 문제 | 내용 |
|---|---|
| **혼용** | 잠실 75개 매장 중 74개 일회용 병행. 다회용기 규격이 1종뿐이라 떡볶이·국수만 담김. 경기 중반부터 편의상 일회용 선포장 |
| **회수** | 다회용기가 일반 쓰레기로 버려짐. 회수율·분실이 사업 성패 좌우 |
| **세척 비용·위생** | 세척장 구축비, 물·에너지, 물류비 → 운영비 상승. 위생 신뢰(RLU 검사) 요구 |
| **수작업 구간** | 세척센터가 자동화돼도 **분류·애벌세척·적재는 사람** — 경기 직후 대량 반납이 몰리는 구간 |
| **정책 제언** | 환경단체: KBO·구단이 사용~반납~세척 통합 운영 기준 마련. 전문가: 보증금 회수, 스마트 반납 인프라, 표준 위생 프로토콜, 공공·민간 비용 분담 |

## 4. 우리 프로젝트가 서는 자리

```
관객 반납 ──▶ [반납구] ──▶ ★ 전처리 (우리) ──▶ 세척기 / 세척센터 (본세척·살균·검수)
                            종류 식별 · 잔반 분리 · 예비세척 · 자세변환 · 트레이 적재 · 수량 기록
```

| 현장 요구 | 우리 대응 |
|---|---|
| 지침의 "대여·반납 수량 전산 관리" | 슬롯·수량·트레이 기록 (역할 C) |
| 세척센터 수작업 구간(분류·애벌세척·적재) | 반납구 DI로 분류, 브러시·패드 예비세척, 슬롯 적재 (A·B) |
| 잔반 섞인 용기가 세척기로 들어가는 문제 | 무게 잔반 판정 → 격리 (B) |
| 경기 직후 대량 반납 | 매장·게이트 단위 셀로 분산 처리 (협동로봇 1대 + 3D 프린팅 지그) |
| 지방 구장 도입률 2~10% | 대형 센터 없이 설치 가능한 소형 셀 |

**과장 금지**: 위생 적합성(20 RLU 등)은 본세척·검수가 담당. 로봇은 "세척기에 넣기 좋은 상태"를 만든다.

## 5. 발표 슬라이드 순서 (제안)

1. 야구장 폐기물 3,444 t/년, 매장 99.7% 일회용 (문제)
2. 정책 흐름: 규제(2022) → 협약(2023) → 서울 도입(2024) → 100억 지원(2025) → 월드컵경기장·경기도 140만 개(2026)
3. 회수율 85% — 그런데 세척은? 청주·양평 센터 사진 + **팀원 제공 사진**: 분류·애벌세척·적재는 손
4. 우리 시스템 8단계 시나리오 (반납 신호 → 적재 → 기록)
5. 비전 없이 어떻게: DI 신호·파지 폭·하중 측정·삽입력
6. 시연 영상·KPI (성공률·사이클 타임·잔반 검출률)
7. 확장: 매장 단위 셀 → 세척센터 앞단 자동화
