### 배운 것
1. **실제 경로 값이 손 측정과 다르다.** 영점까지 닫는 측정(25.10 / 19.30)과 tool() 이 목표 폭(영점 + 기대 − 1.2)으로 닫다 손잡이에 멈춘 값(25.60 / 18.6~19.1)이 0.4~0.5 mm 다르다. → 프리셋 `grip_width_mm` 은 **tool() 경로 값**으로: 수세미 **15.0**, 솔 **8.3**(허용 ±0.6).
2. **솔은 회차마다 0.5 mm 흔들린다.** 반납 때 홀더 바닥을 찾아 놓으므로 솔이 조금씩 다르게 앉고, 손잡이가 아래로 가늘어져 잡는 높이에 따라 폭이 바뀐다. 허용 범위 18.3~19.5 가 실측 18.6~19.1 을 덮고, 빈손(17.68)은 밖이다.
3. **새 프로그램의 첫 grip 은 release 뒤에.** 그리퍼 힘은 움직이거나 닫혀 있을 때만 읽혀서, 첫 실행(18:14)에서 홀더 위까지 간 뒤 grip 첫 줄에서 RuntimeError 로 끝났다. 시험대(rig_f1 CYCLE)가 HOME 에서 release 를 한 번 한다. 제품 흐름(flow_node)은 앞 단계가 그리퍼를 이미 움직여 해당 없음.
4. 수세미 pick 자세(J6 −220°)에서 100 mm 직선 상승·복귀 15회 — 손목 풀림 없음(cell.yaml ⚠ 해소 · 실기 0.3 속도).

## 4. INT-F3 에서 볼 것 — tool(PICK) 의 끝 자세와 soap
- 지금 `tool(PICK)` 은 쥔 뒤 **홀더에서 100 mm(f1.tool_clear_mm) 곧게 빼낸 자세**로 끝난다(접근점이 있으면 그 높이).
- 박진용 #72 의 `soap` 은 "SOAP 자리로 가지 않고 **툴을 집은 자리에서** J6 ±20° 비틀기 3회 → Z ±5 mm → HOME 높이 상승 → HOME". 제품 흐름 `tool(PICK) → soap` 이면 비틀기가 홀더 100 mm 위에서 일어난다 — 세제 컵이 홀더 안이면 세제가 안 묻는다.
- 정하는 법: 박진용의 시험 스크립트가 어느 높이에서 비틀었는지(PR #72 코멘트 답) → (a) 그 높이가 홀더 안이면 tool(PICK) 의 빼내기를 soap 뒤로 미루는 인터페이스 조정(IRD 변경 · 4명 확인) 또는 (b) soap 이 시작할 때 다시 내려가는 것으로. **F4 는 (b) 를 권장** — tool() 의 끝 자세(빼낸 상태)가 IRD 의 "정해진 위치에서 시작·끝" 약속이라 바꾸지 않는 쪽.
